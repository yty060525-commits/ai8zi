## 数据库

[db.mjs](../../server/db.mjs) 第 12–48 行建表：

- `users(id, username, pass_hash, salt, role, created_at)`
- `sessions(token_hash, user_id, expires_at)` + `idx_sessions_expires`
- `records(...)` + `idx_records_user`、`idx_records_user_time(user_id, updated_at DESC, created_at DESC)`（免临时排序）、`idx_records_name`、`idx_records_pillars`
- `settings(key, value)` —— 存 `ai.provider`、`ai.key.<id>`
- `ai_cache(cache_key PRIMARY KEY, chart_sig, payload, created_at)` + `idx_cache_chart_sig`

`chart_sig` 是从缓存键派生的列，老库打开时自动补列回填（同文件第 55–67 行）。有了它，删盘/清缓存不再用前导通配 LIKE 全表扫描，而是索引精确删除，任务缓存与聊天缓存一并清掉。

**注意**：`server/data/*.sqlite3` 是真实用户数据，任何测试和脚本都不得写入或删除。

## 接口速查

路由集中在 [app.mjs](../../server/app.mjs) 第 51–166 行，前缀 `/api/`，除注册登录外都要会话。

| 方法 路径 | 作用 |
| --- | --- |
| POST `auth/register` / `auth/login` / `auth/logout` / `auth/password` | 账号体系；`ALLOW_REGISTER=false` 可关开放注册 |
| GET `auth/me` | 当前用户 |
| GET `records` / POST `records` | 列表（走复合索引）/ 新建 |
| GET · PUT · DELETE `records/<id>` | 单条读写删 |
| POST `records/<id>/ai/task` | 跑一个批断任务（先查缓存，命中不花钱） |
| POST `records/<id>/ai/cache-clear` | 按命盘签名清缓存 |
| POST `chat` | 「问问 AI」聊天 |
| GET · POST `admin/config` | 管理员看/改默认通道与密钥 |
| GET `admin/records` | 管理员全量视图 |
| POST `admin/test` | AI 连通自检（微小消耗） |
| GET `health` 与 `/` | 存活探测与静态回退 |

客户端对应封装在 [serverClient.ts](../../client/src/data/serverClient.ts) 的 `apiAuth` / `apiRecords` / `apiAdmin` / `runTaskOnServer`，见 [12-客户端-数据层](./12-客户端-数据层.md)。

## 运行

```bash
cd server && node --version   # 需 ≥ 22.5（原生加载 .ts 闸门 + node:sqlite）
PORT=8787 node server.mjs
npm test                      # node --test，含 EXPLAIN 索引命中断言
```

环境变量：`PORT`（默认 8787）、`HOST`（默认 0.0.0.0）、`DATA_DIR`、`ALLOW_REGISTER`、`ADMIN_USER` / `ADMIN_PASSWORD`。systemd 单元示例在 [server/README.md](../../server/README.md)。

本端要同时守住三件事：**中文闸门**（直接 import 客户端那份，见 [13](./13-跨端共享与三端一致性.md)）、**提示词逐字节同源**（[prompt-parity.test.mjs](../../server/test/prompt-parity.test.mjs)）、**缓存键版本同步**（`v15`）。桌面侧的对应实现见 [22-桌面端-tauri](./22-桌面端-tauri.md)。
