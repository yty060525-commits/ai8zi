## 约定（改任何模块前先读）

1. **程序负责确定性计算，AI 只做解释**。所有干支、十神、五行、神煞、大运由本地引擎算定后作为事实数据喂给模型，模型禁止自行推算。见 [11-客户端-特性层](./11-客户端-特性层.md) 的排盘引擎一节。
2. **可见文本只能是中文**。模型输出与应用自己拼出来的文案都要过同一道闸门，闸门只有一份实现：[chineseGate.ts](../../client/src/shared/chineseGate.ts)。详见 [13-跨端共享与三端一致性](./13-跨端共享与三端一致性.md)。
3. **修完提示词不等于存量数据变干净**。展示与复制路径必须读取时再清洗一遍，否则旧库里的脏正文照旧上屏。
4. **同一逻辑在三端各有一份**（浏览器 / Node 服务器 / Rust 桌面）。任何口径改动都要同时落三处并升缓存键，判据在两份 parity 测试里。
5. **提交在前、构建在后**。`npm run build` 会把 git 提交序号与短哈希注入产物，先构建再提交会让线上版本号落后一次。
