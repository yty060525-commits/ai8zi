# 简化八字直接入库规格

## [S1] 输入范围

排盘页只保留姓名、性别、出生年、出生月和四柱八字（年柱、月柱、日柱、时柱）。删除客户/亲戚/朋友分类，以及公历、农历模式按钮和相关转换字段。

## [S2] 直接持久化

用户提交后不做复杂历法换算、不做候选年份推断、不做基础命理扩展计算。将上述原始字段直接保存到 Tauri Rust 层的 SQLite 数据库，记录页从数据库读取并展示；应用重启后仍可查询。

## [S3] AI 补充

保存原始八字成功后，使用已经保存的字段请求 DeepSeek，AI 只返回格局、身强身弱、喜忌及简短解释。未配置、失败或格式错误时保留原始记录并显示明确状态。密钥只能从本机配置读取，不写入源码。

## [S4] 页面流程

提交成功后关闭输入弹窗，清除排盘页结果，自动切换到底部第二分类“记录”。记录列表直接显示姓名、性别、出生年月和四柱；详情显示原始输入及 AI 补充结果。删除加载动画和 mock running 状态。

## [S5] 验收

- 只有姓名、性别、年、月、四柱字段，没有分类和公历/农历入口。
- 提交的数据可以在 SQL 中保存并在记录页立即看到，重启后仍存在。
- 不进行复杂计算；保存不依赖 AI 成功。
- AI 失败有状态提示但不丢失原始记录。
- `npm test -- --run`、`npm run build`、Rust SQLite 测试通过。
