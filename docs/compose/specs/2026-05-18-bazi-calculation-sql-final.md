# 八字复杂基础计算与 SQLite 同步规格

## [S1] 输入

保留姓名、性别、出生年、出生月和四柱八字。不要恢复客户/亲戚/朋友分类、公历/农历入口或加载动画。

## [S2] 非 AI 计算

录入时读取运行程序所在设备的当前日期/时间并保存。使用 `lunar-javascript` 对用户输入的年月和四柱执行确定性基础计算，至少保存四柱、农历日期、生肖、五行、五行比例、地支藏干、十神、纳音、日主、神煞/十二长生（库支持的字段）和大运基础数据。AI 不计算这些事实。

## [S3] SQL 同步

原始输入和完整非 AI 计算结果必须在一次 SQLite 记录中保存；记录列表和双击打开的 Tauri 程序都从同一 SQLite 文件读取。AI 分析状态和结果也更新到同一条记录。

## [S4] AI 补充

DeepSeek 只接收已保存的基础数据，补充格局、身强身弱、喜忌及解释；批量运势只询问当前年份起至未来十年，按大运、流年、流月生成。未配置或失败不能阻止原始输入和非 AI 结果保存。

界面不得显示 DeepSeek、模型名称、API 地址、额度、费用或厂商相关信息；界面只显示通用的分析状态和分析内容。

## [S5] 交付与验收

提交成功后立即跳转记录页，记录和详情展示原始输入及非 AI 结果；AI 在后台更新。必须运行前端测试、Rust 测试、`npm run build` 和 `npm run tauri:build`，并确认生成的可执行文件/AppImage 时间晚于本次源码修改。
