# 安全 AI 服务设置规格

## [S1] 设置页

增加独立设置页，允许用户选择当前分析服务并输入对应密钥。界面只使用“服务一/服务二”等中性名称，绝不显示厂商名、模型名、API 地址、额度或费用。密钥输入始终使用密码遮罩。

## [S2] 安全存储

Tauri Rust 层使用操作系统钥匙串保存和读取 DeepSeek/Kimi 密钥。前端只能获得通用配置状态（已配置/未配置/保存失败），不能读取或回显密钥明文。不得写入 localStorage、SQLite、源码、测试 fixture 或构建产物。

## [S3] 服务选择与调用

设置页保存当前 provider 选择；后台分析请求使用对应 provider 的兼容接口和模型配置。主业务只接收统一的分析结果和通用错误状态。浏览器测试使用 mock provider，不读取真实密钥。

## [S4] 验收

- 设置页可保存/清除两种服务密钥并切换当前服务。
- 重启 Tauri 后只能看到已配置状态，不能读取明文。
- 所有页面都没有厂商、模型、密钥、额度、费用信息；设置页也只显示中性服务名称。
- 密钥扫描、前端测试、Rust 测试和 Tauri 构建通过。
